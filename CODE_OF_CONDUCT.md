# Code Link community guidelines

We welcome users and contributors with different experience levels and backgrounds. Keep discussions useful to the people building and using Code Link.

- Discuss the behavior, code or proposal. Explain disagreements with evidence and a suggested next step.
- Be respectful. Harassment, threats, discriminatory remarks and personal attacks are not acceptable.
- Protect privacy. Do not publish another person's personal information, credentials, pairing details or private terminal output.
- Keep issues and pull requests relevant. Avoid spam, misleading claims and repeated promotional posts.

These guidelines apply to this repository's issues, pull requests and other project spaces moderated by the maintainer. You can report abusive content privately through GitHub's **Report content** menu on the relevant post. Security vulnerabilities use the private reporting channel in [SECURITY.md](SECURITY.md).

The maintainer may clarify expectations, edit or remove inappropriate content, close disruptive threads, or restrict participation. Responses depend on the conduct and its impact. Reports and enforcement should respect the privacy of those involved.

## 中文

欢迎不同经验和背景的使用者与贡献者。讨论具体问题和代码，用依据说明分歧，尊重他人。请勿骚扰、威胁、人身攻击或发布歧视性言论，不公开他人的个人信息、凭据、配对信息或私人终端内容，也不发送垃圾信息。

这些规则适用于仓库的问题、PR 及维护者管理的项目空间。违规内容可通过 GitHub 帖子的 **Report content** 私下举报；安全漏洞使用 [SECURITY.md](SECURITY.md) 中的渠道。维护者可视情况说明规则、移除内容、关闭讨论或限制参与，并保护相关人员隐私。
