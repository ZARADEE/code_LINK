# Code Link 下一步

2.0 提供 Windows + Android 互联网远程、横屏终端、滑动与点击，以及 macOS + iOS 原生客户端。Apple 端支持 LAN、托管终端、Codex 授权和 A/B 提醒；iOS 后台暂停连接。以下为按用户使用障碍排列的计划，尚未列出的发布日期由实际验收决定。

| 优先级 | 要改善的操作 | 完成标准 |
| --- | --- | --- |
| v2.0 已实现 | 离开电脑后仍要操作终端 | iroh 直连与公共中继，手机移动数据和平板热点跨网验收 |
| v2.0 已实现 | 手机上文字小、无法翻阅或点按钮 | 横屏全屏、滑动、Back to bottom 点击、返回恢复布局，实体 Android 16 手机验证 |
| v2.0 已实现 | 电脑已授权但手机提示仍保留 | 新状态清除授权提示和系统通知，历史提示不覆盖最新运行状态 |
| v1.4 已实现 | 首次连接时不知道先操作哪一端 | Windows 向导提供授权、USB 通道和 Android 认证三个阶段，确认本次连接后显示成功；常见失败有下一步 |
| v1.4 已实现 | 下载后还要另装 .NET | Windows 包包含运行时；桌面、CLI、后台代理与输入桥接均完成独立启动检查 |
| P0 | 升级与安装来源的信任 | 维护稳定 Android 发布签名、升级说明和 SHA-256；制定 Windows 签名和版本检查方案 |
| P0 | 从 README 看不出实际工作流程 | 录制从真实任务、授权到 A/B 完成横幅的短视频，展示操作和耗时 |
| P2 | 在应用内直接切换语言 | 当前已提供 zh-CN / en 独立语言包；后续加入无需重新安装的语言选择 |
| v1.4 已实现 | 手机上横向工具栏和状态区域拥挤 | 窄屏列表/详情切换，平板双栏；草稿随会话保存，快捷键可滚动；360dp / 412dp 窗口和键盘验收，继续收集不同厂商手机记录 |
| P1 | 状态未知、失败和完成不容易理解 | 增加文字状态说明和上次同步时间，保留未知状态；提醒不能把断线或失败算为成功 |
| P1 | 多窗口和长任务更难定位 | 搜索、置顶、状态筛选；先验证多个真实并行任务的切换、输入归属和提醒 |
| P1 | Wi-Fi 与不同设备的可靠性证据不足 | 完成 LAN 真机连接、蓝牙锁屏、跨厂商后台和 8 小时连接及耗电记录 |
| P2 | 修改 Android 页面需要阅读大量内联 Java | 拆分界面与连接状态、迁移标准资源布局和 Gradle，确保新环境可构建 |
| P1 | Apple 发布与真实设备验证 | Developer ID 公证、TestFlight、iPhone / iPad 真机网络和电池验收 |
| 待需求验证 | Linux、WSL 与更多代理 | 先收集具体需求与可测试设备，再选择下一平台或协议 |

欢迎从[问题模板](https://github.com/ZARADEE/code_LINK/issues/new/choose)提交设备兼容记录或实际操作障碍。翻译准备、连接恢复、文档和设备验收是当前适合参与的工作。
