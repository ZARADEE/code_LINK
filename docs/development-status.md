已交付桌面托盘客户端、代理、clink、ConsoleBridge、Android APK。已验证当前 Codex 扫描、真实外部终端 USB/蓝牙输入、确认提示、托盘与最小化后操作、USB 映射自恢复、Codex MCP 权限及表单提交。APK 已安装到测试平板。

2026-11-13 本轮修复：桌面只保留统一命令行列表；卡片独立边框和选中高亮；移动端自动选中新映射窗口并显示真实文本；修复长快照截断和显示重排；重复启动唤回已有 WPF 面板，避免测试中原生 ShowWindow 只显示黑色窗口外壳。

1.1.0 新增：移动端 A/B 标签、默认 B、每个命令行切换分组、重命名；未读红点与确认；B 组统计本轮参与任务并在全部完成时提醒。平板同步完整扫描目录，可点击尚未映射的窗口主动连接。已用真实任务与真机确认提示验证，记录见 `research/pad-reminder-acceptance.json`、`research/pad-window-alert-acceptance.json`。Codex 窗口增加基于明确界面标记的状态识别，无法识别时保留未知状态。

1.1.1 修正：B 组全部完成后，逐个查看会确认对应终端的完成提醒；最后一个完成红点消除时，B 标签和汇总行的红点自动消除，同时撤回系统完成通知。部分已读和全部已读状态在 App 重启后保留。B 部分完成不标红、授权立即提醒的规则保持不变。

1.2.0 新增：连接、输出缓存与提醒由 Android 连接设备前台服务持有；A 逐个完成、B 全部完成发送系统横幅，支持通知回到对应终端/分组；后台设置入口显示通知、勿扰和电池优化状态。真机已看到 A/B 完成横幅，完成了后台内容更新、页面回收后连接、熄屏通知测试。用户解锁后已验证最新完整输出恢复，临时任务已清理，原来的 B 分组及勿扰设置已恢复；最终验收结果见 `research/pad-background-acceptance.json`，输出画面见 `research/background-restored-output.png`。
