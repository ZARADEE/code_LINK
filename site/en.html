01 / OUTPUT AND INPUT

Your terminal can stay minimized

Choose an existing Windows terminal on the tablet. Send text, Enter, arrow keys or Ctrl+C back to that terminal.

02 / A AND B REMINDERS

One task, or the whole batch

A alerts when each task finishes. B waits for every participating task to complete successfully. Approval requests alert immediately in both groups.

03 / BACKGROUND NOTIFICATIONS

Switch apps and stay informed

An Android foreground service receives updates while you use other apps. Completion notifications open the relevant task.

Read output and send input from your tablet

START WITH USB

Connect with a data cable.

You need Windows x64 with .NET 10 Desktop Runtime, and Android 9 or later. Landscape tablets are the primary layout.

Get .NET 10 Desktop Runtime →
  1. Install both clients

    Extract the complete Windows ZIP and run CodeLink.exe. Install the APK on Android and allow notifications.

  2. Authorize USB debugging

    Enable Developer options and USB debugging on Android. Connect a data cable, unlock the tablet and authorize your computer.

  3. Connect and select a terminal

    On Windows choose 连接设备 → USB 一键连接 (Connect device → USB quick connect). Select a terminal on the tablet, or map it from the desktop panel.

Download the current version
