01 / INTERNET ACCESS

Step away and stay connected

Keep Code Link running on your awake PC, then connect Android over mobile data or another Wi-Fi network. No rented server or separate VPN app required.

02 / A AND B REMINDERS

One task, or the whole batch

A alerts when each task finishes. B waits for every participating task to complete successfully. Approval requests alert immediately in both groups.

03 / PHONE CONTROLS

Turn, scroll and tap

Open landscape fullscreen from the top right, then return from the top left. Scroll the terminal and tap interactive text buttons. Requests resolved on the PC clear automatically.

START REMOTELY

Pair once. Connect across networks.

Windows x64 and Android 9+ on ARM64 phones or tablets. The Windows v2.0.0 ZIP includes the runtime. Keep your PC on and awake while accessing it remotely.

Read the installation guide →
  1. Install both clients

    Extract the complete Windows ZIP and run CodeLink.exe. Install the APK on Android and allow notifications.

  2. Enable remote access and pair

    On Windows choose Pair device → Enable remote access and wait for the node to be ready. Scan the invitation on Android or import its text. Invitations expire after 10 minutes.

  3. Choose a terminal and try input

    Select a terminal and online device, then share it with Android. Switch the phone to mobile data and send echo hello in a test terminal to check both directions.
