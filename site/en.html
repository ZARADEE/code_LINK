START WITH USB

Connect with a data cable.

You need Windows x64 and Android 9 or later. The Windows v1.4.0 ZIP includes the runtime. Landscape tablets are the primary layout.

See three complete workflows →
  1. Install both clients

    Extract the complete Windows ZIP and run CodeLink.exe. Install the APK on Android and allow notifications.

  2. Authorize USB debugging

    Enable Developer options and USB debugging on Android. Connect a data cable, unlock the tablet and authorize your computer.

  3. Connect and select a terminal

    On Windows choose Pair device → Connect over USB. Wait for USB connected on Android, then open a terminal from the tablet's list.

0 / 5 steps checked

Extract all Windows files and open CodeLink.exe. Keep the included runtime files beside the EXE; no separate runtime install is needed. Install the Android APK and open Code Link.

Use a data cable, unlock Android and allow this computer's debugging request. If the tablet is absent, try another cable or USB port. In the Windows app folder, run tools\adb.exe -P 5037 devices -l, then try port 5038. unauthorized means Android needs your confirmation.

In Windows, choose Pair device → Connect over USB. Keep both apps open. Pairing runs over the cable; no manual IP entry is needed.

Tap a terminal on Android. Or select a terminal and an online device in Windows, then choose Share with device. Use a test terminal for your first input.

Send echo hello and press Enter if needed. You should see hello in the selected terminal. For alerts, open Background & alerts on Android and allow banners and background activity.
