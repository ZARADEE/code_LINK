WINDOWS 终端 + 你的 ANDROID 平板

闲置平板，
变成终端任务看板。

电脑继续跑构建、测试和 Codex，手边的平板查看输出、发送输入、处理授权。一个任务结束就提醒，或等整批任务完成再看。

选择适合的安装包 ↓连接第一个终端 →

本地 USB / 蓝牙 · 无需账号与中转服务器 · Mac 支持托管终端 · iOS 开发预览

01 / 观测与输入

终端收起，进度还在

扫描电脑上现有的命令行，在平板选择窗口。文字、Enter、方向键和 Ctrl+C 都能回到对应终端。

02 / 分组提醒

按你的节奏提醒

A 组每个任务完成就提醒。B 组等本轮运行过的任务全部完成。需要授权或回答时，两组都立即提示。

03 / 后台通知

切到其他 App，也能收到

Android 前台服务维持连接，后台继续接收状态。任务完成时显示系统横幅，点开即可回到对应任务。

START WITH USB

一根数据线，开始连接。

Windows x64 需要 .NET 10 Desktop Runtime。Android 最低版本为 9，当前优先适配横屏平板。

获取 .NET 10 Desktop Runtime →
  1. 安装两个客户端

    从 Releases 下载 Windows ZIP 和 Android APK。完整解压桌面包，运行 CodeLink.exe；在平板侧载 APK。

  2. 允许 USB 调试

    在平板开启开发者选项和 USB 调试，连接数据线并允许这台电脑。USB 用途可选文件传输。

  3. 连接并选择终端

    两端打开 Code Link，在电脑点击“连接设备 → USB 一键连接”，选中终端和设备，映射到移动端。

一步一步，连接第一个终端

完成一步就勾选一项。清单仅在当前页面记录进度，不会检测你的设备。

已勾选 0 / 5 步

完整解压 Windows 包并打开 CodeLink.exe。若提示缺少 .NET，请安装 .NET 10 Desktop Runtime x64。在 Android 安装 APK 并打开 Code Link。

使用数据线连接，解锁平板并允许电脑调试请求。找不到设备时，换一根数据线或 USB 接口。在 Windows 应用目录执行 tools\adb.exe -P 5037 devices -l，也可尝试端口 5038。unauthorized 表示需要在 Android 确认授权。

在 Windows 点击 连接设备 → USB 一键连接。保持两端应用打开，配对通过数据线完成，无需手动填写 IP。

在 Android 点击终端；也可在 Windows 选中终端和在线设备，再点击 映射到移动端。首次输入请选择测试终端。

发送 echo hello，需要时再按 Enter。对应终端应显示 hello。要启用提醒，请在 Android 打开后台与通知，允许横幅与后台运行。

当前支持什么

连接方式与验证范围
连接使用方式验证情况
USBADB reverse + TLS，需要 USB 调试授权真机输入、后台通知与 89 分钟连续连接
蓝牙系统配对 + 应用鉴权，使用 RFCOMM，无需 PAN真机输入与重连已验证
局域网本地 TCP / TLS，需要两端网络可达已实现，真机直连验收待完成

现有 Windows Terminal 窗口映射跟随活动标签页，同步终端可读取的文本。任务完成提醒需要明确状态标记；使用 clink codex 可获得结构化回合与授权事件。macOS 支持在 Code Link 中创建的终端；iOS 使用局域网连接，后台暂停。Linux 和 WSL 尚未完成适配或验收。
